每个编辑器组件都是基于chrome组件构建的--顶部的按钮条以及左侧的侧边壳，这些将在每章中重复使用和扩展。

### Editor Navbar

创建 `components/editor/editor-navbar.tsx`

要求：

- 顶部导航栏的高度是固定的。
- 它分为三部分，左侧是控制侧边栏是否收缩的图标按钮，中间是标题，右侧是操作按钮。
- 使用 `PanelLeftOpenIcon` / `PanelLeftCloseIcon` 图标作为侧边栏的展开/收起图标。
- 右侧区域现在是一个空区域，后续会添加操作按钮。
- 背景色是黑色的，并且底部有一个微妙的边框。

### Project Sidebar

创建 `components/editor/project-sidebar.tsx`

要求：

- 侧边栏应该浮在在编辑器画布之上。
- 侧边栏打开时不应该影响编辑器画布的布局。
- 侧边栏应该是从左侧滑动展开的。
- 接受一个 `isOpen` 属性，用于控制侧边栏是否展开。
- 侧边栏头部应该有一个 `Project` 标题，以及一个关闭按钮。
- 使用shadcn-ui的 `Tabs` 组件进行标签切换，名称分别为：
  - `我的项目`
  - `分享`
- 标签内容初始为空
- 底部有一个新增项目按钮,并且按钮中存在一个 `PlusIcon` 图标

### Dialog Pattern

使用 `global.css`中现有的颜色来为对话框设置样式。

支持：

- 标题
- 描述
- 底部操作按钮

暂时不要创建实际的对话。
